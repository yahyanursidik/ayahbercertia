# Ayah Bercerita — Website Design Pack

Domain rencana: `ayahbercerita.my.id`

Paket ini memuat brief produk, rancangan UI/UX, spesifikasi integrasi YouTube, dan prototype HTML responsif. Prototipe memakai **data contoh**, bukan hasil sinkronisasi channel nyata.

## Isi
- `01-PRODUCT-BRIEF.md` — visi, audiens, scope, kebutuhan, acceptance criteria.
- `02-UI-UX-LAYOUT.md` — sitemap, arsitektur informasi, design tokens, wireframe, layout semua halaman.
- `03-YOUTUBE-INTEGRATION.md` — alur YouTube API, playlist, sync, cache, failure, SEO, dan privasi.
- `04-CLAUDE-CODE-INSTRUCTIONS.md` — instruksi implementasi untuk Claude Code.
- `prototype.html` — prototype visual mandiri, responsif, dengan pergantian tampilan Beranda / Jelajahi Video / Cerita Anak / Catatan Ayah / Detail.

## Cara melihat desain
Buka `prototype.html` di browser. Gunakan navigasi dan kartu video untuk berpindah tampilan. Tidak membutuhkan internet atau instalasi.

## Prinsip
- Content-first, mobile-first, visual edukatif yang bersih.
- Tanpa ilustrasi manusia/hewan dan tanpa simbol dekoratif yang tidak relevan.
- Video publik dari YouTube otomatis disinkronkan secara terjadwal.
- Tidak perlu CMS, database, atau login untuk MVP.
